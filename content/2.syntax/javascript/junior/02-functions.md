# Functions

Eerste-klasse waarden in JavaScript. Twee hoofdvormen.

## Function-declaratie

```js
function add(a, b) {
  return a + b
}
```

## Arrow-functie

```js
const add = (a, b) => a + b
```

## Higher-order

Functies die functies returnen of accepteren — basis voor map/filter/reduce.
